THE EVOLUTION JOURNEY

體感平衡遊戲的研發演進歷程

從初期的單腳本體感覺訓練，到線上的物理重力對戰，最終融入 Minecraft 方塊風《BALANCE CRAFT》。

PHASE 1

🎯 本體感覺與三關體感訓練起點

動靜態平衡

設計三大針對性訓練關卡，結合前庭覺與雙重任務（Dual-tasking）：

  • 靜態鎖定：單腳 90 度支撐 + 拋接網球 / 逢 3 倍數拍手干擾。
  • 鐘點羅盤：單腳屈膝點擊四方 (12/3/6/9點) + 反方向視線轉頭鎖定。
  • 瞬時突襲：雙眼閉合 + 0.5 秒隨機聽覺拍手張眼極速報數。
PHASE 2

🌌 重力物理與線上多人連線對戰

即時連線 1v1

導入 2D 向量重力物理場與多人線上同步對戰機制（WebSocket/Lobby 房號系統）：

  • 星核對對決 (1v1 Clash)：雙方艦艇釋放引力脈衝拉拽中央星核至敵方邊界。
  • 雙人協同保衛：兩人共同編織重力防禦網，彈開太空站反物質隕石。
PHASE 3

🔲 超界限平方：量子矩陣賽博朋克

Arcade 幾何

打造全方位的霓虹 Arcade 矩陣幾何遊戲體驗：

  • 矩陣躍遷 (Leap)：8x8 塌陷網格避障與晶體搶收。
  • 平方脈衝 (Burst)：同色區塊連鎖爆破與重力下落 Combo。
  • 四方防衛 (Defense)：360 度向量脈衝格擋。
PHASE 4

🧱 終極殿堂：《BALANCE CRAFT》方塊體感大成

現正上線

結合經典像素方塊美學與實時倒單擺物理學（Inverted Pendulum Physics），將體感姿態修正、微感調整與緊張刺激的疊疊樂遊戲完美融合！
